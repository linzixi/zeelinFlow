# 项目数仓智能问数报告

参考案例：[DeerFlow 舆情分析：热点事件追踪报告](https://blog.csdn.net/weixin_26850469/article/details/158019003)。本地阅读快照是 `output/research/csdn-page.yml`。复现执行摘要、观点与典型原文、情感分布、时间线、话题演变、来源分布与建议的结构，统计和结论使用本项目真实数据。

## 在画布使用

1. 打开项目 → 画布与预警，选择既有上汽通用画布。
2. 双击“上汽通用 · 智能问数报告”，在“处理要求”用自然语言描述问题，例如：“哪些车型出现负面问题？列出原文，区分视频转写与源正文，分析平台来源和情感变化。”
3. 设置北京时间开始/结束，或选择“跟随本次运行时间”。保存后运行报告节点；完整工作流会在前序数据处理完成后自动运行报告。
4. 运行记录 → 报告节点 → 输出产物。支持 HTML 与 SVG 在线预览、Word/Markdown 下载；查询审计 JSON 保存查询口径、数据集、文章版本和引用编号。

时间按入库时间左闭右开；日/周/月报应先采集足够时间范围的数据，再设置报告区间。只有五分钟样本时，报告不能宣称七日增长、全网热度、意见领袖影响力或机器人识别。

## 查询算子

本次通过 DeerFlow 原生 `ModelTool` 注册 `warehouse_query`，模型看到的实际工具名由宿主添加扩展前缀。它提供数据库 MCP 所需的受控查询能力，直接集成既有网关，不额外启一个数据库服务。

| operation | 参数示例 | 返回 |
| --- | --- | --- |
| overview | `{ "operation": "overview" }` | 总量、情感、分析/审核/转写状态分布 |
| breakdown | `{ "operation": "breakdown", "dimension": "platform", "limit": 50 }` | 平台、来源、车型、问题、情感或审核状态分组 |
| timeseries | `{ "operation": "timeseries", "interval": "minute" }` | 北京时间入库桶与情感计数；可用 hour/day |
| articles | `{ "operation": "articles", "sentiment": "negative", "limit": 20 }` | 原文证据、URL、版本、标签、证据限制 |

支持 `keyword` 字面匹配、`article_ids` 和 `offset` 分页。所有 SQL 参数绑定；不提供任意 SQL、数据库密码或跨项目参数。数据集上限一万篇，时间序列上限五百点，超过时明确提示缩小范围或扩大粒度。

每次工具调用校验宿主登录人、当前团队、角色、项目和线程绑定。审核员不可调用；跨线程、跨团队也不可调用。失败节点重试保留冻结数据，换新线程重查；旧线程不能继续访问该数据集。

## 可信报告链路

MySQL 已入库文章 → 冻结文章版本 → Agent 真实调用只读算子 → 保存查询编号及结果 hash → 验证引用 → 服务端生成统计表/百分比/SVG → Agent 基于证据解读 → HTML、Word、Markdown、查询审计产物。

全量总览、时间线、平台/问题/来源分布必须使用无过滤基准查询。分类分页会注明展示数量；文章检索可以筛选。未完成标注单独记为 unknown，人工修订优先。未匹配原文的人工/模型摘录不会作为原文引用，报告回退至现有正文或标题并说明限制。

HTML 是独立静态文档，转义原始资料、限制内容安全策略；工作台 iframe 沙箱预览。Word 包含可编辑标题、文字和统计表，独立 SVG/HTML 保存图表。

默认宿主 `recursion_limit=400`：DeerFlow 每次模型/工具循环包含多个中间件步骤，原默认100不足以完成多轮问数；仍受宿主上限1000和任务超时约束。模型网关故障会使节点失败并保留回执，可在修复后只重试该节点。
